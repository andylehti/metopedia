= Editorial guide =
Use direct prose. Prefer definitional openings, stable sectioning, and restrained claims. Articles should read like reference entries rather than promotional pages.

== Basic article pattern ==
# lead section defining the topic
# scope and context
# key distinctions or subtopics
# references where needed
# categories at the end

== House preferences ==
* separate claims from examples
* distinguish quotation from paraphrase
* keep titles stable once linked widely
* prefer explicit uncertainty over vague certainty
