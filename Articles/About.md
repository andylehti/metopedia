= About Metopedia =
Metopedia is a static reference repository designed for GitHub Pages. It uses a stable encyclopedia shell to render repository-based page files, while keeping the written content in ordinary folders that can be revised independently of the interface.

== Purpose ==
The project is intended for interdisciplinary inquiry. Its recurring areas include cognitive psychology, educational conditioning, textual and linguistic analysis, mathematical and computational logic, and institutional or forensic inquiry.

== Structure ==
* Pages live in folders rather than inside the shell.
* Navigation, tools, and footer links are generated from repository files.
* Categories, sitemap pages, search pages, and related special pages are generated dynamically from the site index.
