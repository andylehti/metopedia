Metopedia: MB3I / MBTI Browser Lab

A client-side analysis utility for MBTI pattern recognition. It uses local JSON model files from assets/json/mbti/ to score TXT data. All processing is performed locally within the browser.

Built-in models: the lab loads MB3I and MBTI datasets from assets/json/mbti/manifest.json, so the HTML stays small and models can be updated without editing the page.

Features:

  • Scoring and Charts: Analyze text files and chart vote patterns.
  • Testing Suite: Compare models and evaluate NFJ mirror/turbulence.
  • Axis Helpers: Use 16-type reference sets for I/E or J/P mapping.
