This section defines language folders for translated page variants. If a translated page uses the same page filename/slug as a base page (for example `/Canonical_Order_of_Operations/` and `/languages/es/Canonical_Order_of_Operations/`), Metopedia will automatically show a language switcher on that page.

| Language | Code |
|---|---|
| Mandarin | `zh` |
| Spanish | `es` |
| Hindi | `hi` |
| Portuguese | `pt` |
| Russian | `ru` |
| Japanese | `ja` |
| Turkish | `tr` |
| Korean | `ko` |
| German | `de` |
| French | `fr` |
| Iranian Persian | `fa` |
| Italian | `it` |
| Latin | `la` |

> Translation pages should set front matter including `lang`, `title`, `description`, and `slug_name`.
